# Faster cutting with the same bottleneck

In a fictional packaging line, Cutting can process 60 units per hour and Assembly can finish 40 units per hour. There is enough demand, and neither station has downtime. Each finished unit passes through both stations.

After an upgrade, Cutting can process 75 units per hour. Assembly still limits line throughput to 40 finished units per hour. If Cutting keeps releasing work above 40 units per hour, unfinished units build up in front of Assembly.

## What changes the output

If Assembly improves to 50 units per hour and the other operations can keep up, the line can finish 50 units per hour. If Assembly improves enough, the bottleneck may move to a different step.
